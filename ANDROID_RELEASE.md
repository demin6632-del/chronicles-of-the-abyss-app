# Chronicles of the Abyss — Android Release

## Текущее состояние

- Android-приложение использует `applicationId` `com.pokoritel.bashni`, поэтому будущие обновления могут устанавливаться поверх предыдущей версии при сохранении той же подписи.
- Текущая игровая модель — **один постоянный герой, непрерывное покорение Башни, без забегов и без сброса персонажа**.
- Android Release/Test workflow берёт новую игру из корневого `tower_game.html` и помещает её в `assets/game.html` во время сборки.
- Внешние HTTP/HTTPS-запросы блокируются; APK рассчитан на автономную работу.
- `localStorage`/DOM Storage включены для постоянного сохранения героя и прогресса.
- Release APK проверяется через `apksigner`.
- Для тегов `v*` GitHub Actions публикует APK и SHA-256 как GitHub Release.
- Версия Android-приложения повышена до `3.0.0` (`versionCode 3`).

## Игровые системы текущей версии

- 6 классов героя: Воин, Маг, Разбойник, Паладин, Чернокнижник, Следопыт.
- Оружие и броня с экипировкой.
- 50 этажей Башни.
- 5 боссов: 10, 20, 30, 40 и 50 этажи.
- Квесты за победу над боссами.
- Опыт и уровни.
- Навыки классов.
- Зелья и отдых.
- Постоянное сохранение прогресса.
- При поражении герой не создаётся заново: путь продолжается с предыдущего этажа.

## Production Release

Для production Release APK нужны четыре GitHub Actions Secrets:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

Приватный keystore нельзя хранить в публичном репозитории.
